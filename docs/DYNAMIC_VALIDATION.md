# 全画面字幕模式验收（2026-10-03）

## 结果与适用范围

独立新增 `dynamic` 模式及 `SubtitleStudioDynamic` 应用。任意位置、多个对象并存、每个事件期间位置基本稳定、文字逐步生成。已完成真实本地 OCR、API 文本翻译、MP4/SRT 输出及实际桌面流程验证。原三个模式和应用包保留。

本次验证证明首版流程可用，不能推出真实漫画式字幕的总体正确率。目前提供的真实视频主要是底部字幕加少量其他位置文字，仍缺真实多气泡视频样本。

## 识别与生命周期

- 全画面每 0.2 秒发现文字，活动对象之间插入局部复读，采样间隔 0.1 秒。按空间位置与文字关系关联，按邻近行组成段落；不把整个画面的文字拼接为一句。
- 各对象独立确认完整候选、数字/否定词换句、消失及重新出现。相同文字同时在不同位置仍有独立 ID。
- OCR 对首字母后的一段增长过程可能暂时无读数。局部字形像素的持续存在可延续可见时间，但不增加文字的 OCR 票数或完整候选证据。空白/不同字形会停止此延续。
- 取消检查点包含活动对象、候选、局部证据及像素签名。继续处理恢复活动对象。人工校对的时间段受重新识别保护。
- 自动确认需多帧支持；低证据对象保留原画面。用户可以忽略、调整局部框、确认、撤销、明确合并两个对象或按时间拆分。区域划分单帧复读的结果默认待确认。

## 像素视频验收

使用自行绘制的 20 秒 1280×720/30fps 视频，识别输入只有压入画面的像素。参考标注没有传给识别引擎。视频包括同时逐字生成、短句、两个位置的相同文字、原位置消失后重现、位置跳变、双行正文和无字幕间隔；显式排除测试水印。

| 检查 | 结果 |
| --- | --- |
| 独立事件、整句文本 | 9/9，无额外事件 |
| 首次出现/结束最大误差 | 0.05 秒 / 0.05 秒 |
| 同屏译文 | 实际导出帧含三个并行中文字幕 |
| 中文像素 OCR 抽查 | 9 次均检测到中文，含不同位置同一句 |
| 无字幕时段覆盖残留 | 6 个整帧抽查通过，平均像素误差 <4/255 |
| 完整视频/音频 | 解码 600 视频帧，音频存在；分辨率与 20 秒时长保持 |
| SRT | 9 个事件；位置由项目/MP4 保存 |

中文像素抽查是存在性检查，不是逐字译文准确率评估。文字翻译结果另外保存在私有项目中供校对。

| 上方文字和底部字幕并存 | 7 / 3 | 5 次中文像素抽查通过，包含同屏两个区域；480 视频帧和音频 |

## 限制

首版不是气泡分割器。邻近、对齐的两个气泡可能被误合并；背景文字可能误检。几何关系不能完全取代气泡边界，需要手工划分/忽略。全画面原生 OCR 对小于约画面高度 2% 的细小文字可能漏读；短于 0.2 秒发现间隔的事件可能漏检。完整候选指有证据的 OCR 候选，不保证语义已经说完。

当前只支持清晰横排且事件期间基本静止的文字。连续移动、旋转、复杂特效、淡入遮挡恢复、无痕背景修复、中文逐字动画和其他机器的打包运行尚未验证。局部覆盖会覆盖框内背景；并行框冲突会提示调整。字体不足、译文未翻译/过期或译文无法装入框时阻止导出。顶部没有足够上方空间时，保留外文的中文向画面内靠拢，用户需核对排版。

详细日志、OCR 证据、真实片段成品、合成参考与隔离基线保存在本地忽略目录 `artifacts/dynamic-20261003/`，不公开。
