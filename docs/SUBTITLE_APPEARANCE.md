# 中文字幕覆盖与局部去字

“中文显示”现在提供三种显示方式，四种识别模式均可使用：

- **背景覆盖外文 → 贴合原字幕**：根据 OCR 的正文文字边界绘制背景，默认保留 4 个视频像素的边距，遮住英文描边和阴影。中文自动换行并在必要时缩小字号，背景不会为了容纳译文额外扩大。固定区域内遇到极短原文、中文放不下时，使用原识别区域的排版宽度，让有描边的中文向外延伸，覆盖范围仍保持原文字大小；全画面对象模式继续要求译文能放入对象框，以免串到相邻对象。
- **背景覆盖外文 → 完整识别区域（原方式）**：保留过去按整个识别框覆盖的效果，可自行调整背景颜色和边距。
- **局部去字 · 无背景条（实验）**：先用 FFmpeg `delogo` 按每帧区域边缘的像素插值填补原文，再绘制有描边的中文。全程本地，不下载模型或上传画面。该选项没有背景条，但并非通过透明颜色消除原文。
- **保留外文，中文在上方**：不去除原文。

完全透明的背景无法遮住已印在视频中的文字，半透明背景同样会透出原文。局部去字适合纯色、缓慢渐变等简单背景；纹理、人物、运动细节可能模糊、拉伸或闪烁，无法保证恢复原画面。它也不会消除原视频已经存在的字幕面板。复杂画面优先尝试贴合覆盖，去字前先生成短片预览。

## 原项目与显示时机

新项目默认贴合覆盖，旧项目没有 `coverArea` 字段时继续使用完整识别区域；打开旧项目不会自动修改其设置。旧高质量结果已经保存 `body_box`，切换后可直接使用。旧标准/逐步模式未保存文字边界时暂用原框，界面会提示：在不含人工校对结果的片段重新识别，或另建项目获得边界。原四个 macOS 应用包保留；新的 macOS 包为 `SubtitleStudioAppearance.app`，设置与项目使用独立目录。

新标准/逐步识别会保存全画面坐标的 `source_box`，逐步出现的文字覆盖范围取其增长过程的并集。高质量模式将裁剪区域内的 `body_box` 正确换算至画面坐标，全画面模式使用各对象的已确认范围；人工调整对象框优先于旧 OCR 证据。

背景覆盖与去字使用原字幕的出现区间，独立于人工修改的中文时间；全画面模式仅处理已确认、未忽略对象，在可见区间之外保留画面。预览只执行与片段相交的去字区间。去字区域需留有边缘采样像素，紧贴最外侧边缘的原文可能残留；区域过小会提示改用背景覆盖。播放器上的中文是位置示意，**生成效果预览**才是实际排版与去字结果；修改样式会使旧预览失效。

输出继续使用已有导出流程，保持视频比例、帧率和音轨，保存新视频，不覆盖源文件。非方形像素或奇数显示尺寸会按原导出规则归一化为方形像素、偶数编码尺寸，可能产生一两个像素的舍入差异；音频使用原有 AAC 有损编码。原视频中的画面经过有损编码后，区域之外也可能出现编码差异；滤镜本身只在指定区域和时间工作。

## 验证

`tests/test_appearance.py` 使用真实 FFmpeg 检查局部去字的空间和半开时间边界，并检查正文坐标换算、增长范围、原项目兼容、去字没有背景条、视频导出尺寸和音频。`tests/windows_acceptance.py` 同时验证四种模式以及打包后端的局部去字预览。macOS 打包命令为 `npm run package:appearance`；Windows 使用原打包流程并纳入 `worker.appearance`。

真实素材的短片外观测试使用中性中文占位文字，单独比较原覆盖范围、贴合覆盖和局部去字，不作为语义翻译证据。另外已通过实际打包的 Mac 应用完成约 22 分钟的全画面对象识别、真实 API 翻译与整片导出，逐帧解码验证全部 79,806 帧、音轨和源文件哈希，并在原生界面验证成片播放。该项目仅翻译已确认对象，未确认候选保留供校对，不保证所有装饰、动画和弱识别文字都已翻译。

日文多行素材使用高质量模式的“完整区域 · 保留所有文字行”，将角色名和多行正文按上下顺序作为一个字幕候选送入真实翻译服务；约 7 分钟成片已完成全部 25,891 帧解码、音轨及源文件检查，三行、四行字幕的成片抽查包含完整中文。自动 OCR 和译文仍需人工校对，抽查不能替代全片语义验收。真实视频、字幕内容、帧图、项目数据和服务凭据均不提交至 GitHub。

另外一段约 61 分钟的英文素材通过实际打包 Mac 后端完成 873 条真实译文和整片导出，全部 109,836 帧解码通过，输出保持 1920×1080、30 fps 与原时长，音轨内容及同步抽查通过，源文件哈希未变化。全部译文能够放入文字覆盖范围，无需扩大背景；7 个实际帧时间戳的中文抽查均与预期文字一致，包含原文有 6 行的字幕。原始识别候选另行保留，交付项目仅移除无文字证据的占位候选。成片抽查按实际解码帧时间戳匹配字幕，避免换句边界附近把下一句的画面与上一句文本误比。
